# Gestión de requerimientos – Nutriverde Módulo 2

Repositorio usado como herramienta de gestión de requerimientos (Fase 4, curso Análisis y especificación de requerimientos – UNAD).

- **Issues**: cada hallazgo (H-01…H-06) y cada requerimiento (RS, RF, RNF, RI) es un issue.
- **Etiquetas**: tipo, prioridad (P1/P2/P3), estado, objetivo y caso de uso.
- **Sub-issues**: cada requerimiento del sistema (RS) agrupa sus RF/RNF/RI.
- **Project**: tabla, tablero por estado, priorización y trazabilidad.
